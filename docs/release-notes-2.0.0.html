PrismPack 2.0 beta. UpdateScout is now PrismPack, and it does much more than update.

  • New name, same app. Your settings, history, hidden lists and background check carry over. The app renames itself to PrismPack.app, and because macOS sees a new app it asks again for notifications and Full Disk Access (optional).
  • A new window: a sidebar with Updates, Installed, Orphaned App Files, Discover, Activity and Settings, in the Liquid Glass look on macOS 26 and later (simpler on macOS 15). Cards or a list on the main pages.
  • Discover: find and install new apps, tools, fonts and extensions from Homebrew, npm, PyPI, crates.io, RubyGems and the editor stores, with descriptions, pictures and font previews.
  • More updates: Python (pipx and uv), npm, Rust, Ruby gems, VS Code, VSCodium and Cursor extensions, Apple's own apps through Software Update, and your own sources.
  • Faster, clearer installs: several updates at once, one password per batch, and a progress bar with a percent and a step line.
  • Installed, Duplicates and Uninstall: everything on your Mac in one list, two copies of an app compared side by side, and removal to the Trash with the files an app left behind.
  • Orphaned App Files and optional Full Disk Access to clear what macOS protects.
  • You decide: Stable or Beta per app, automatic updates (off until you turn them on), and more ways to hide updates.
  • Settings: search, a tool list with Install and Reinstall, and release notes for every version.
  • Light on memory: about 15 MB in the menu bar, and closing the window frees much of what it was using.

This is a beta. Full details are on the GitHub release page.
