Custom sources

Edit custom_sources.json for apps nothing else covers.
There is no unified API for third-party driver updates on macOS. Vendors like DisplayLink ship their own installers. PrismPack uses Homebrew's cask database as a version oracle for those, and the custom-sources file for anything without a cask.

App icon: the rainbow deck

Final, 29 Oct 2026. Six cards from red to violet, a clear glass front card with a rainbow sheen, and the 3D prism that the menu bar glyph matches. Rendered by Apple's ictool. Source: docs/prismpack-icon-final/, and the app builds it from Resources/AppIcon.icon.

The password prompt on its own
