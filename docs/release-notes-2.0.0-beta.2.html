PrismPack 2.0.0 beta 2. Fixes from the first beta.

  • One copy, always the newest. Starting PrismPack a second time shows the first copy's window. Starting a newer build closes the older one, so there is never a second menu bar icon or window.
  • Homebrew apps that wouldn't update. Apps Homebrew can't replace on its own (owned by another user or by root) used to fail again and again in the background. They now wait for you and ask for your password when you press Update. A leftover copy from an earlier failed upgrade gets a Repair and Update button, and the failure shows Homebrew's real message. If an automatic update hits one, a notification tells you.
  • No endless retries. After two failures in a row, automatic updates stop trying that app until a new version arrives. Updating by hand still works.
  • One password prompt, and it says why. Both password prompts are now the same native alert, and say what the password is for and what set it off, for example "to update Signal, which you started". Skip is now Cancel.
  • Notifications have Open and Dismiss buttons, and are removed from Notification Center once you use them.
  • Daily cleanup. Once a day PrismPack clears Homebrew's old versions and downloads, and the pip and npm caches, and logs what it freed in Activity. Nothing you installed is removed. You can turn it off in Settings.
  • Set up window. The first launch opens a Set up window: Homebrew and mas first, then optional Full Disk Access with what it is for. Settings shows "Granted" with how to turn it off, and the wording follows your macOS version.
  • Look-alikes. Apps that share one bundle ID but have different names (such as two editions of one product) are shown as look-alikes, with nothing suggested to remove.
  • Check for Updates moved to the PrismPack section at the top of Settings.

Full Disk Access on macOS 27.3 is still in beta. Apple changed how it works in the 27.3 beta (a new list, adding apps with + instead of dragging, and optional folder-by-folder access). PrismPack's steps for 27.3 may change until 27.3 is released. macOS 15 and 26 are unchanged.

This is a beta. Full details are on the GitHub release page.
