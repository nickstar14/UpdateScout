# PrismPack app icon: layers for Icon Composer

Chosen 29 Oct 2026: the rainbow deck with violet in front and the 3D prism.
Generated by `../prismpack-icon-concepts/generate_final.py`. `preview.png`
roughly approximates each appearance. It is not an Icon Composer render.

## How macOS icon appearances work

Researched 29 Oct 2026 from Apple's WWDC25 session "Create icons with Icon
Composer" and two write-ups (sources at the end). Not yet checked against
the macOS 27 version of Icon Composer.

- **One `.icon` file covers every appearance.** You don't make separate
  icons. Icon Composer has three appearances to edit:
  - **Default.** Used in light mode, and the normal icon.
  - **Dark.** Used in dark mode.
  - **Mono.** Drives the four remaining modes: **Clear Light, Clear Dark,
    Tinted Light and Tinted Dark.** The system makes those from Mono, so
    there's no separate Clear or Tinted artwork.
- **Per-appearance variants.** With an appearance selected, any layer or
  group property can be overridden for just that appearance: fill, opacity,
  blend mode, Liquid Glass on or off, shadow, specular, and the layer's image
  itself (drop in a different file as that appearance's variant).
- **Up to 4 groups** (depth levels). Layers live inside groups, and glass,
  blur, translucency, shadow and specular are set per group.
- **Artwork rules.** Flat, opaque, full 1024 x 1024 canvas, no rounded mask.
  SVG for vector shapes (convert text to outlines). Simple background colours
  and gradients go in Icon Composer's own fill rather than as a layer.
- **Mono rule.** At least one element should be close to white. Map the rest
  to greys. Keep shadows **Neutral** in Dark and Mono.
- **Into the app.** Our build compiles `Resources/AppIcon.icon` with `actool`
  (see `scripts/build-app.sh`), so the finished file replaces that one,
  keeping the name `AppIcon.icon`.

## Transparency is built in

Every layer except the background has a slight transparency baked into its
file, so it looks right as soon as it's imported:

| Layer | Built-in opacity |
|---|---|
| Cards 01 to 06 | 85% |
| 07-front-card | 30% (clear glass the cards show through) |
| 08-front-sheen | 45% |
| 09-prism-light | 95% |
| 10-prism-shade | 85% |

**Leave Icon Composer's Opacity at 100%** for these. Its slider multiplies on
top of the built-in value, so 50% there would make a card about 43%. Lower
it only to fine-tune. This departs from Apple's "flat and opaque" advice,
because Nick wanted slight transparency on every layer.

The front card is the next size step after violet (540 wide against
violet's 500), so the deck grows toward the viewer.

## The three folders

Each folder holds the same filenames, so each layer has a Default file and,
where needed, a Dark or Mono variant of it.

| Folder | Appearance | What's different |
|---|---|---|
| `default/` | **Default** (light mode, the normal icon) | Silver background, full rainbow, white front card, rainbow sheen |
| `dark/` | **Dark** | Midnight background, softer lavender front card so it doesn't glare, deeper prism shade |
| `clear/` | **Mono** (Clear and Tinted) | Pale greys, the prism as the one pure-white element, no sheen, no background (the system draws it) |

## Step by step in Icon Composer

1. **New icon.** Set the canvas background fill to a gradient:
   - Default: `#ffffff` to `#eef1f8` to `#d6dceb`, top-left to bottom-right.
   - Dark (switch to the Dark appearance first): `#24345f` to `#141d3d` to `#0a0f24`.
   - `00-background.svg` in each folder is the same gradient, if you'd rather
     import it than type the colours.
2. **Import the `default/` layers** (everything except `00-background`) and
   arrange them into **3 groups**, bottom to top:

   | Group | Layers | Liquid Glass | Group settings to start with |
   |---|---|---|---|
   | **Cards** | 01 to 06 (red to violet) | On | Neutral shadow, light translucency |
   | **Front** | 07-front-card, 08-front-sheen | 07 on, 08 off | **High translucency**, specular on. Optionally set the sheen's blend to Soft Light or Overlay |
   | **Prism** | 09-prism-light, 10-prism-shade | Off, or light glass | Specular on, neutral shadow |

3. **Dark.** Select the Dark appearance and, for each layer that has a file
   in `dark/` that differs (07-front-card, 10-prism-shade), drop that file
   on as the Dark variant. The cards and the sheen are the same files and
   need nothing. Set shadows to Neutral.
4. **Mono.** Select Mono and drop each `clear/` file onto its layer as the
   Mono variant. **Hide 08-front-sheen** (opacity 0) in Mono. Check that the
   prism stays the brightest thing and the shade face still shows the 3D.
5. **Check every preview:** Default, Dark, Clear Light, Clear Dark, Tinted
   Light, Tinted Dark, at large size and at 32 and 16 px.
6. **Save as `AppIcon.icon`** and hand it over. It replaces
   `Resources/AppIcon.icon`.

All settings above are starting points, not tried in Icon Composer. Tune by
eye.
