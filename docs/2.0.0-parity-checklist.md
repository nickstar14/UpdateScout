# 2.0 must keep everything 1.8.0 does

Written 29 Oct 2026. Rule for 2.0: **add, never remove.** This lists what 1.8.0
has today, found by reading the code, so each item can be ticked off before a
2.0 beta ships. The mockup in [2.0.0-mockups.html](2.0.0-mockups.html) shows
every section below.

## Update sections (all kept)

| 1.8.0 section | Source id | Colour today | Notes to keep |
|---|---|---|---|
| Homebrew | `homebrew` | brown | Formulae and casks together, not casks only. |
| Mac App Store | `mas` | blue | Apps the App Store must update collapse into one hand-off card. iPhone and iPad apps are labelled. |
| macOS | `macos` | graphite | "Update macOS" opens System Settings. Installs happen there. |
| Other apps (via Homebrew data) | `caskOracle` | teal | Warns when an update switches an app to Homebrew management. |
| Drivers & extensions | `components` | purple | Vendors with no cask use the custom-sources file. Some need a restart. |
| Sparkle apps | `sparkle` | yellow | Release tracks, beta markers, and `minimumSystemVersion` as in 1.8.0. |
| Custom sources | `custom` | green | From `custom_sources.json`. |
| Leftover drivers | n/a | grey | Per-item "Ignore this one" and remove, with confirmation. |
| Hidden | n/a | grey | Everything ignored, each with a way back. |

New in 2.0 and added alongside these: Python (pip), npm global, Editor
extensions, and later sources from the vision doc. Colours for the new ones must
not repeat the table above: pip is orange, npm red, editor extensions indigo.

## Per-item features (all kept)

- Installed to available version on every item, with the app's real icon.
- Info popover: installed and available version, major-upgrade warning, "What's
  new" notes, release-notes link and info page.
- **Update**, with Repair replacing it for a stuck Homebrew upgrade.
- **Ignore this version.** The ID includes the version, so the next version shows again.
- Open info page, and Show in Finder.
- Caveat tooltips ("requires restart", "will switch this app to Homebrew management").
- Progress line and Cancel while installing, and an error line when it fails.

## Window and menu features (all kept)

- Per-section collapse, remembered between launches, and a button on each
  header: "Update all <section>" or "Update <section>".
- **Update All** and **Check Now**, "Checking…", and "Checked 2 minutes ago".
- The major-upgrade review sheet before a batch that includes major jumps,
  with "Skip these, update the rest".
- A banner listing sources that failed to check.
- "Nothing to do" empty state.
- Menu bar icon states (spinner, count, checkmark), the live badge, and the
  menu bar popover with Check, Settings and Quit.
  **Changed on purpose (Nick, 29 Oct 2026):** the popover is removed. Left-click
  opens the window, and right-click shows a native menu with Open PrismPack,
  Check Now, Settings… and Quit. So Check, Settings and Quit all stay
  reachable. See section 3.4 of the build guide.
- Notifications for new updates, and the background check agent.
- `--open-window`, `--open-settings`, `--background-check` and `--askpass`
  launch arguments.
- Settings: Setup (dependencies), Background checking, Appearance (theme, glass,
  Dock icon), per-source toggles, and the custom-sources file.
- Two processes write `state.json` through `Store.mutate`, and item IDs keep
  their format so ignored and notified lists survive the upgrade.

## Decisions that change how these look (not what they do)

- **Cards to rows.** 1.8.0 shows each update as a card in a grid. The mockup
  uses rows. If you want the grid kept, say so. Nothing is lost either way.
- **Update by section** already exists in 1.8.0 as the header pill. The mockup
  keeps it.
- **App Store and macOS stay in Updates**, and stay out of Discover.

## New ignore options (additions, not replacements)

Opened from the app's icon or name in a floating card:

1. **Ignore this version.** Exists today.
2. **Ignore updates from this app.** New. Stored as a separate list keyed by
   source and install token, **without the version**, so the item ID format
   does not change and existing ignored lists survive.
3. **Ignore major upgrades only.** New. Still offers minor fixes, and ties into
   the major-upgrade review.

Ignored apps show in Hidden with "Bring back".
